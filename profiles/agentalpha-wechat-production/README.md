# AgentAlpha 微信公众号生产规范

这是 AgentAlpha 公众号文章的可携带生产包。它把“新文案 → 排版 → 配图 → 用户验收 → 草稿箱回读”固定成一套可供 Codex、Claude Code、Grok、Cursor、OpenCode 等 agent 读取的规则。

## 适用范围

- 用户给出一篇完整正文，要求排版、配图并放入微信公众号草稿箱。
- 用户说“保留”后，才进入上传草稿阶段。
- 默认只保存草稿，不发表、不群发。
- 用户提供的完整正文是只读真源；排版、配图和发布过程不得改写正文。

## 标准流水线

1. **锁稿**：保存正文副本、标题、作者、摘要和正文 SHA-256。
2. **排版规划**：为每个图位写正文锚点、认知目标、图型、冻结标签和验收标准。
3. **配图**：默认长文 8–10 张；完整技术面试/Agentic RL 长文优先 10 张。至少包含封面、结构/架构图、4–6 张机制图和 1 张总结/行动入口图。
4. **技术与语义 QA**：检查尺寸、可解码、文字、箭头、手机缩略可读性和内容对应关系。
5. **用户验收**：全部图片展示给用户；用户说“保留”或明确给出修改编号之前，不上传草稿。
6. **草稿上传**：复用已登录 Chrome/固定 profile，只保存草稿；遇到登录失效立即停止，不循环重试、不自动扫码。
7. **强制回读**：只有拿到真实 `appmsgid`/`media_id`，并回读标题、作者、摘要、正文、图片数和封面状态后，才可报告“草稿已保存”。

## 视觉默认值

- 画布：`1280×720`、16:9、通栏安全边距。
- 质感：暖白/奶油白纸张、近黑手绘线、局部彩色语义、高密度但有留白。
- 动作：每张图至少有两项动态线索，例如有方向箭头、回环、放大镜、被打断气泡、倾斜便签、前后景遮挡或不对称留白。
- 信息：一张图只服务一个认知锚点；主路径必须能从左到右或从上到下追踪。
- 品牌：右上角只出现一次 `agentAlpha`；不出现对标作者名、平台水印或右下角广告署名。
- 文字：只渲染冻结标签；禁止段落字、伪中文、随机数字和模型自造结论。
- 风格参考：学习参考图的信息层级、留白、箭头和颜色语义，不复制参考图的人物、文案、构图签名、logo 或水印。

## 人物形象规则

- 默认不放人物；机制图优先用对象、箭头、状态和证据表达。
- 确实需要情绪或叙事时，才使用 AgentAlpha 讲解角色；每 3–5 张图最多 1 张，人物面积不超过 20%。
- 人物只承担一个可读动作：追问、等待、发现错误、回退、验收或松气；不能当装饰贴纸。
- 人物参考图只锁定比例、动作和情绪节奏，不固定发型、服装、动物或外部账号角色。
- 不复制“小林 coding”等外部账号的角色、署名、口号和水印。

## 结尾与课程引流

结尾只从 `templates/cta-templates.md` 选择，并按文章实际内容填充。课程名称、阶段、项目、链接、二维码和领取方式必须有真实来源；没有真实来源时使用占位符，不得编造。

推荐课程信息可包含：Agent 从 RAG 到 Agentic RL 的进阶路线、Search-R1、PPO/GRPO、Observation Token Masking、分层奖励、异步 Rollout、环境隔离、Verifier/红队审计、生产级实验报告和项目评估。每篇文章只保留与正文自然衔接的一种 CTA，不堆多个广告块。

## 发布安全门

- 固定复用用户已登录的 Chrome profile；不复制 Cookie，不提交 Cookie、AppSecret、二维码或带 token 的完整 URL。
- 无界面模式默认开启，避免抢前台和打扰用户工作。
- `WECHAT_LOGIN_REQUIRED`、Chrome 控制端不可用或网络状态未知时，报告阻塞，不声称成功。
- 上传前只读检查同标题草稿；存在同标题时停止，禁止盲目重复上传。
- “本地预览正常”不等于“远端草稿已保存”；必须用真实 `appmsgid`/`media_id` 和强制刷新后的远端回读证明。
