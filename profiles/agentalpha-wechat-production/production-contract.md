# AgentAlpha 公众号生产合同

## Copy lock

- 用户提供的完整正文、代码块、引用、标题层级和 CTA 原文均视为锁定内容。
- 只允许补充 frontmatter、图片锚点和 Markdown 结构，不得润色、删段、改数字或替换课程承诺。
- 发布前保存 `source_sha256`；排版副本去除图片锚点后应与锁定正文逐字一致。

## Image count and slots

### Default count

- 短文：4–6 张，仅在正文长度确实不适合 8–10 张时使用。
- 长技术文：8–10 张。
- 完整 Agent/Agentic RL 面试深度文：优先 10 张。

### Preferred 10-slot recipe

1. `cover`：首问或核心冲突。
2. `architecture`：全文对象、模块或流程总览。
3. `mechanism-1`：第一个关键机制。
4. `mechanism-2`：度量、数据或账本。
5. `mechanism-3`：错误方案 vs 正确方案。
6. `mechanism-4`：上下文、权限或状态边界。
7. `mechanism-5`：工具、脚本或环境动作。
8. `mechanism-6`：模型路由、成本或异步调度。
9. `cta-or-checklist`：执行清单或课程承接。
10. `summary`：3–5 个结论，帮助读者复述。

每 2–4 个主要段落判断一个图位；没有认知增量的段落不强行插图。两张大图之间必须有正文转折。

## Prompt contract

每张生图提示词必须写清：

- 主体：对象、角色和动作；
- 场景：纸张、分区、层级和阅读方向；
- 构图：图型、箭头、路径、留白和不对称；
- 风格：暖白底、近黑手绘线、彩色语义、手机端清晰；
- 文字：冻结标签，逐字渲染，只允许列表中的短标签；
- 画幅：`1280x720`；
- 参考图：绝对路径或可携带相对路径，并声明“只学习信息层级，不复制人物、文案、logo、署名或水印”；
- 负面：企业 PPT 网格、等距节点、对称卡片墙、伪中文、随机英文长句、平台水印、赛博霓虹、空洞单物件海报。

推荐提示词骨架：

```text
AgentAlpha 公众号中文技术讲解图，16:9，1280x720，暖白纸张，近黑手绘线，手机端清晰。
附图只学习图型的信息层级、箭头、留白和颜色语义，不复制人物、原文、logo、署名或水印。
主阅读路径：<对象> → <动作/依赖> → <结果>。
场景与构图：<主体、分区、动作、留白、不对称线索>。
冻结标签（逐字，只允许这些）：［标签1｜标签2｜标签3］。
右上角仅一次 agentAlpha。
禁止段落字、伪中文、随机数字、企业 PPT 网格、等距节点、对称卡片墙、平台水印和旧固定角色。
```

## QA gates

1. 技术门：PNG 可解码、`1280×720`、RGB/RGBA、provider receipt、`quality=low`、SHA-256。
2. 文字门：冻结标签逐字可读，无伪字、叠字和自造数字。
3. 结构门：静音可复述“对象 → 动作/依赖 → 结果”，箭头不穿字，缩略图仍可扫读。
4. 风格门：手绘不规则、局部不对称、动作优先；不是三列等宽企业海报。
5. 排版门：图片与正文锚点匹配，正文图下不自动添加小说明或 AI caption。
6. 人工门：联系表/页面预览经用户确认后，图片才进入 `publish-assets/` 和草稿。

## Draft receipt

回执至少包含：`source_sha256`、`title`、`author`、`summary`、`appmsgid`、`media_id`（如有）、`profile_or_cdp`、`draft_only: true`、10 张图片的绝对路径与 SHA-256、强制回读结果和验证时间。
