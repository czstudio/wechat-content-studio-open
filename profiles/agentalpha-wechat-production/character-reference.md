# AgentAlpha 人物形象参考

## Default identity

AgentAlpha 不依赖固定动物或外部账号角色。默认以结构化技术图解释机制；人物只在需要表达面试追问、发现漏洞、等待结果、回退或验收时出现。

## Optional presenter

- 形象：简洁、亲和、可辨认的 Q 版技术讲解员；表情明确，动作服务信息。
- 动作：指向流程、拿放大镜检查、举手追问、等待测试、发现红色警告、把错误路径推回去。
- 比例：人物占画面不超过 20%；每 3–5 张图最多出现 1 张。
- 颜色：服装和配色服从当前图的语义，不固定为某个外部角色的颜色或发型。
- 品牌：右上角 `agentAlpha` 只出现一次，不使用右下外部署名。

## Prompt fragment

```text
可选 AgentAlpha Q 版技术讲解员，只承担“追问/检查/回退/验收”中的一个动作；人物小比例、与箭头和节点发生关系，不是装饰贴纸。保持手绘线和暖白纸张，不复制参考图人物的发型、服装、角色身份或水印。
```

## Negative constraints

```text
禁止固定动物、白机器人复刻、外部账号角色、网红脸、写实肖像、人物墙、人物占满画面、无动作贴纸、平台水印、伪中文。
```
